依頼の概要

Web 広告（Facebook 広告・ディスプレイ広告など）に使うバナーです。①〜⑥の6種類があり、演習ではこの中から1種類以上を選んで作ります。ホームページや今のバナーのデザインにとらわれず、まったく異なるテイストが歓迎されています。

ターゲット

  • 3歳〜小学生の子供を持つ親（主に母親）

訴求するサービス

  • 低年齢（3歳から）で参加できるプログラミングスクール
  • 年少以下向けにはイベントを実施。年中から通える
  • 小学校のプログラミング教育必修化に対応している
  • 1対2〜3の個別指導で、1人1人に合わせた指導
  • 無料体験会を随時実施中

6種類のバナー（1種類以上選ぶ）

①〜④ 無料体験必須：「無料体験」「入会金無料キャンペーン3月31日まで」。訴求文はそれぞれ ①3、4、5歳児向け ②小学校プログラミング教育対応 ③個別指導 ④マイクラでプログラミング（若干の変更は可）
⑤ 春休みイベント春休みプログラミングイベント／3月23日〜4月6日／KOOVでロボットプログラミング／Scratchでゲーム作り／1DAYイベントと2DAYSイベントあり／対象は幼児〜小学校低学年（若干の変更は可）
⑥ LINE登録LINE 公式アカウントへの登録を促す。必須：「LINE登録」「入会金無料・LINE特別クーポン」。登録のメリット：プログラミングに関する情報発信、イベントの先行案内、無料のキャンペーン、LINE 特別クーポンの発行

入れなくてもよいもの（コンセプトに応じて）

  • 写真、会社ロゴ、サブコピー（内容自由）
  • CTA（入れる場合は LINE 公式アカウントへの動線にする）
  • 教室名：プログラミングスクール CotoMirai
  • 最寄駅：六本木駅・六本木一丁目駅
